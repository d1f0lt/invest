# ADR-0013: Мобильный клиент на Flutter

## Контекст

Нужен клиент для Android и iOS.

## Решение

- Клиент на Flutter (Material 3), общий код для Android и iOS.
- Состояние — синглтоны на `ChangeNotifier` без сторонних
  state-менеджеров.
- Токены — в `flutter_secure_storage`; избранное и мелкие настройки —
  в `shared_preferences`.
- Адрес API задаётся при сборке (`--dart-define=API_BASE_URL`).
- Распространение — подписанный APK в GitHub Releases.

## Последствия

**Положительные:** одна кодовая база на две платформы; минимум зависимостей.

**Отрицательные и риски:** нет автотестов; iOS-сборка не публикуется;
нет офлайн-режима и кэширования данных между запусками (кроме избранного).
