# ADR-0007: Идемпотентный импорт по `external_id`

## Текущее состояние

- У каждой строки отчёта есть стабильный `external_id`, одинаковый в любом
  отчёте, где эта строка встречается:
  - сделки Сбера: `sber:<счёт>:trade:<номер сделки>`;
  - денежные строки (у них нет номера): хеш от счёта, даты, валюты,
    описания, суммы и порядкового номера среди одинаковых строк дня.
- В БД — частичные уникальные индексы
  `(portfolio_id, external_id) WHERE external_id IS NOT NULL`.
- `ImportReport` вставляет всё в одной транзакции с
  `ON CONFLICT DO NOTHING` и возвращает счётчики созданных и пропущенных
  строк. Статус импорта `done` ставится в той же транзакции.

## Последствия

**Положительные:** повторная загрузка, пересекающиеся периоды и повторная
доставка задачи не создают дублей; обработка «всё или ничего».

**Отрицательные и риски:** корректность зависит от стабильности
`external_id` в парсере каждого брокера.
