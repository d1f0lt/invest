# ADR-0004: `.proto` только у владельца, никаких общих Go-модулей

## Контекст

Общее правило проекта — **копия DTO у каждого сервиса вместо общих
internal-пакетов**, ради независимой выкатки. Например, `gateway` и
`parser` дублируют `task.ReportUploaded`, а у `parser` была своя копия DTO
`portfolio`. Переход на gRPC ([ADR-0003](0003-grpc-internal-communication.md))
поставил вопрос, где хранить контракты.

## Текущее состояние

- `.proto` лежит **только** у сервиса-владельца, в папке
  `backend/services/<owner>/proto/`.
- Клиенты (`gateway` — все контракты, `parser` — только `portfolio`) через
  `make proto` копируют `.proto` владельца, генерируют код в
  `internal/<name>pb/` и удаляют копию. `make clean` удаляет
  сгенерированный код; у владельца `clean` не трогает сам `.proto`.

## Последствия

**Положительные:** один источник истины на контракт; правило «без общего
кода между сервисами» соблюдается без исключений; регенерация одной
командой.

**Отрицательные и риски:** после правки `.proto` нужно перегенерировать код
у всех клиентов;
