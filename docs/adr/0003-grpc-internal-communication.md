# ADR-0003: gRPC для межсервисного взаимодействия

## Текущее состояние

- `users`, `portfolio`, `securities_reader` стали
  **gRPC-only**. HTTP-серверная часть удалена целиком и не оставлена ни
  как fallback, ни для обратной совместимости.
- `gateway` и `parser` стали gRPC-клиентами.
- `gateway` перешёл с reverse proxy на явную трансляцию HTTP ↔ gRPC. Каждый
  обработчик декодирует JSON, вызывает gRPC и кодирует ответ в прежний
  JSON.
- `x-user-id` передаётся как metadata через маленький пакет `internal/authmd`,
  своя копия которого есть в каждом сервисе.

## Последствия

**Положительные:** контракты описаны в `.proto`; типизированные клиенты;
стандартные коды ошибок; reflection для `grpcurl`.

**Отрицательные и риски:** в gateway появился ручной слой трансляции для
каждого маршрута; для сборки нужен `protoc` (см.
[ADR-0004](0004-proto-ownership.md)).
