# ADR-0012: Уведомления о цене: отдельный notifier, опрос БД и Telegram

## Текущее состояние

| Вопрос | Решение |
|---|---|
| Где живут алерты | отдельный сервис `notifier`, таблицы `alerts`, `telegram_links`, `telegram_link_tokens` |
| Защита от спама | алерт **срабатывает один раз** (`status = triggered`); снова проверяется только после редактирования пользователем |
| Канал доставки | **Telegram-бот** вместо push: не нужна apple подписка за 99$ |
| Получение обновлений бота | long polling `getUpdates`, без webhook: не нужен публичный эндпоинт |
| Ложные срабатывания | проверяются только бумаги в торгах с котировкой свежее 5 минут |
| Алерты по просадке портфеля | не реализованы |

## Последствия

**Положительные:** нет новой инфраструктуры (брокера, push-сертификатов);
спам исключён самой моделью однократного срабатывания.

**Отрицательные и риски:** `notifier` работает только в одном экземпляре на
токен бота (иначе 409 на `getUpdates`); локальный запуск с боевым токеном
ломает production-бота; задержка срабатывания до 1 минуты.
