# ADR-0014: Графики читаются из БД, свечи загружает price_updater

## Контекст

`securities_reader` запрашивал свечи в MOEX (для экономии памяти) и кешировал. Скорость
открытия графика зависела от внешнего API; после перезапуска кэш был пуст.

## Решение

- Только `price_updater` обращается к MOEX за свечами.
- Отдельная фоновая задача загружает официальные 10-минутные свечи
  последнего торгового дня каждой бумаги на настроенных режимах торгов.
  В БД хранится последний успешно загруженный день, включая объём и оборот.
- Дневные свечи продолжают загружаться ночной задачей; недельные вычисляются
  из дневных. Глубина истории задаётся `BACKFILL_DAYS`.
- `securities_reader` читает свечи только из БД. До загрузки 10-минутных
  свечей нового дня использует сохранённые часовые.
- Перенос загрузки описаний и дивидендов в `price_updater` описан
  в [ADR-0015](0015-reader-database-only.md).

## Последствия

**Положительные:** открытие графика не создаёт запросов в MOEX. Сбой MOEX задерживает обновление,
но не мешает чтению сохранённых данных.

**Отрицательные и риски:** фоновый проход делает запросы для каждой бумаги и может длиться дольше
минуты; между бумагами есть пауза, опрос цен выполняется независимо.
`5y` показывает только уже загруженную историю. Для глубокой истории нужно
увеличить `BACKFILL_DAYS` и повторно запустить первичную загрузку.
См. [сценарий обновления цен](../03-runtime-scenarios.md#34-обновление-цен-price_updater).
