# 7. Мобильное приложение

## 7.1. Общие сведения

| Параметр | Значение |
|---|---|
| Фреймворк | Flutter 3.47.5 (stable), Dart SDK ^3.13.4, Material 3 |
| Платформы | Android (публикуется APK) |
| Зависимости | `flutter_secure_storage` (токены), `shared_preferences` (избранное и настройки), `file_picker` (выбор отчёта), `url_launcher` (открытие Telegram) |
| Управление состоянием | синглтоны-хранилища на `ChangeNotifier` (`PortfolioStore`, `AlertsStore`, `FavoritesStore`), без сторонних state-менеджеров |
| Тесты | автотестов нет (каталога `mobile/test` нет); в CI выполняется только `flutter analyze` |

## 7.2. Экраны и используемые маршруты API

| Экран | Что показывает | Маршруты |
|---|---|---|
| Вход / регистрация | формы с валидацией | `POST /login`, `POST /users` |
| **Главная** | стоимость портфеля, прибыль, изменение за день, пассивный доход, график стоимости, топ изменений за день, состав | `/portfolios/{id}/pnl`, `/portfolios/{id}/history`, `/prices` |
| **Календарь** | полученные и ожидаемые дивиденды по месяцам и список выплат | `/portfolios/{id}/cash-operations`, `/securities/{secid}/dividends` |
| **Портфель** | «Активы» и «Операции» выбранного портфеля, загрузка отчёта | `/portfolios/{id}/pnl`, `/trades`, `/cash-operations`, `/brokers`, `/reports` |
| **Уведомления** | список алертов, создание и редактирование, подключение Telegram | `/alerts`, `/telegram`, `/telegram/link` |
| **Профиль** | данные аккаунта, смена пароля, удаление, выход | `/me`, `/me/password`, `/logout` |
| Карточка актива | цена, изменение за период, вкладки «Обзор / Дивиденды / В портфеле», избранное | `/prices`, `/prices/{secid}/candles`, `/securities/{secid}/info`, `/securities/{secid}/dividends` |
| Поиск активов | поиск по тикеру, названию, ISIN | `/securities?q=` |
| Портфели | список, создание обычного и составного, переименование | `/portfolios` |

Периоды «3м» и «6м» на графике бумаги строятся на клиенте из ответа
`range=year`.

## 7.3. Сессия и сетевой слой

- После входа пара токенов сохраняется в `flutter_secure_storage`
  (Keychain на iOS, Keystore на Android). При запуске сессия
  восстанавливается, если refresh-токен ещё не истёк.
- Access-токен обновляется заранее, за 60 с до истечения.
  Одновременные обновления схлопываются в один запрос, чтобы не
  сработало обнаружение повторного использования токена на сервере.
- На `401` клиент один раз обновляет пару и повторяет запрос. Если обновить
  не удалось (`400`/`401`), сессия очищается и показывается экран входа
  (`Session.onExpired`).
- После старта приложение делает фоновый `GET /me`: если аккаунт удалён,
  сервер вернёт `401` и пользователя вернёт на экран входа.
- Таймаут запроса — 15 с.

## 7.4. Хранение данных на устройстве

| Данные | Хранилище | Примечание |
|---|---|---|
| токены | `flutter_secure_storage` | шифруется средствами ОС |
| избранные бумаги | `shared_preferences` | только справочные поля, цены всегда запрашиваются заново |
| отметка «Подключить Telegram позже» | `shared_preferences` | флаг `_telegramSkipped` в `AlertsStore` |
| справочник названий бумаг | память процесса | подгружается через `GET /prices?tickers=…` один раз за запуск |

## 7.5. Сборка и запуск

Локально (gateway на компьютере разработчика):

```bash
cd mobile && flutter pub get
```

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8080
```


Release-сборка выполняется в CI по тегу `v*`
([подробнее](09-deployment.md#95-релиз-android-приложения)):

- `versionName` берётся из тега, `versionCode` — номер запуска workflow;
- `API_BASE_URL=https://d1f0lt-invest.duckdns.org:8443`;
- подпись release-ключом из секретов, сборка с debug-подписью отклоняется.

Локально без `android/key.properties` release подписывается debug-ключом.
