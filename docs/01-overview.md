# 1. Обзор системы

## 1.1. Назначение

**invest** — система учёта личного инвестиционного портфеля частного инвестора
на Московской бирже (MOEX). Пользователь загружает отчёт брокера, а система:

- восстанавливает по нему полную историю операций по счёту: сделки,
  пополнения и выводы, дивиденды, купоны, погашения, налоги, комиссии;
- считает текущие позиции, реализованную и нереализованную прибыль, доход
  от выплат и изменение стоимости за день;
- показывает стоимость портфеля во времени, цены и графики бумаг;
- присылает в Telegram уведомления о достижении целевой цены.

## 1.2. Основные функции

| Область | Функция | Где реализована |
|---|---|---|
| Аккаунт | регистрация, вход, обновление и отзыв JWT токенов, смена email, логина и пароля, удаление аккаунта | `users`, `gateway` |
| Портфели | несколько портфелей у пользователя; составной портфель из нескольких обычных | `portfolio` |
| Учёт операций | импорт отчёта брокера (сейчас поддерживается СберИнвестиции в формате HTML) | `gateway`, `parser`, `portfolio` |
| Аналитика | позиции, P&L (метод средневзвешенной стоимости), доход от выплат, стоимость портфеля по дням, изменение за день | `portfolio` |
| Рыночные данные | текущие цены (обновляются раз в минуту), свечи для графиков, поиск бумаг, карточка бумаги, история и прогноз дивидендов | `price_updater`, `securities_reader` |
| Уведомления | ценовые алерты (по цене или по проценту), доставка в Telegram | `notifier` |
| Клиент | мобильное приложение Android/iOS: главная, календарь дивидендов, портфель, уведомления, профиль, поиск, избранное | `mobile/` |

## 1.3. Внешние участники

| Участник | Роль |
|---|---|
| Инвестор (пользователь) | ведёт портфели, загружает отчёты, смотрит аналитику, настраивает уведомления |
| MOEX ISS API | источник справочника бумаг, текущих цен, исторических и внутридневных свечей, описания бумаг |
| dohod.ru | источник истории и прогноза дивидендов (MOEX ISS дивиденды больше не отдаёт) |
| Telegram Bot API | доставка уведомлений и привязка чата пользователя |
| Брокер (СберИнвестиции и др.) | косвенно: пользователь выгружает из него отчёт и загружает файл в приложение |

## 1.4. Состав системы

Входит в систему:

- backend: 7 Go-сервисов, PostgreSQL, S3-хранилище (SeaweedFS), RabbitMQ,
  обратный прокси Caddy;
- мобильный клиент на Flutter;
- CI/CD на GitHub Actions и скрипты развёртывания.

## 1.5. Технологический стек

Базовый стек (Go, PostgreSQL, Docker Compose)

| Слой | Технологии |
|---|---|
| Backend | Go 1.24, `net/http` (gateway), gRPC + Protocol Buffers (внутренние вызовы), `log/slog` (JSON-логи) |
| Хранилища | PostgreSQL 16, SeaweedFS (S3 API) с клиентом `minio-go` (умеет работать со всеми s3 хранилищами), RabbitMQ 3 |
| Клиент | Flutter (Dart SDK ^3.13), Material 3, `flutter_secure_storage`, `shared_preferences`, `file_picker`, `url_launcher` |
| Инфраструктура | Docker, Docker Compose v2, Caddy 2 (TLS от Let's Encrypt), GitHub Actions, GitHub Container Registry, DuckDNS |
