# Иконки брокеров

Файлы из этой папки gateway отдаёт без авторизации по адресу
`/static/brokers/<файл>` (встроены в бинарник через `go:embed`, после
добавления файла нужно пересобрать образ gateway).

Путь к иконке брокера хранится в `portfolio`, таблица `brokers`,
колонка `icon_url` (например `/static/brokers/sber.png`). Если файла нет,
приложение рисует первую букву названия на фирменном цвете (`color`).

Рекомендуемый формат: PNG, квадрат 128×128 или больше.
